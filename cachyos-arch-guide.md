# Руководство по работе с CachyOS / Arch Linux: `debtap` и сохранение настроек

Данное руководство содержит инструкции по установке Ubuntu/Debian (`.deb`) пакетов в Arch-подобных системах (CachyOS, Manjaro, EndeavourOS и др.), а также по резервному копированию и восстановлению внешнего вида и настроек рабочего стола (на примере KDE Plasma).

---

## 1. Конвертация и установка `.deb`-пакетов через `debtap`

В Arch Linux и CachyOS основным источником ПО являются официальные репозитории и **AUR** (Arch User Repository). Однако если нужного приложения нет в AUR, а разработчик распространяет его только в виде `.deb`-файла (для Ubuntu/Debian), на помощь приходит утилита `debtap` (*DEB To Arch Package*).

> ⚠️ **Важно.** `debtap` — это крайнее средство. Прежде чем конвертировать `.deb`, проверьте:
> 1. Наличие пакета в официальных репозиториях (`pacman -Ss имя_пакета`).
> 2. Наличие пакета в AUR (`yay -Ss имя_пакета` или `paru -Ss имя_пакета`).
> 3. Наличие Flatpak- (`flatpak search`) или AppImage-версии у разработчика — они часто работают стабильнее и обновляются автоматически.

### Шаг 1. Установка `debtap`

Установите утилиту из AUR с помощью вашего AUR-помощника:

```bash
yay -S debtap
# или
paru -S debtap
```

*(В CachyOS по умолчанию чаще всего используется `paru`.)*

### Шаг 2. Инициализация и обновление баз данных

Перед первым использованием, а затем периодически (раз в 1–2 месяца), обновляйте базы соответствия пакетов Debian/Ubuntu и Arch:

```bash
sudo debtap -u
```

Без этого шага конвертация может завершиться ошибками из-за устаревших маппингов зависимостей.

### Шаг 3. Конвертация `.deb` в формат Arch (`.pkg.tar.zst`)

Перейдите в каталог с загруженным `.deb`-файлом и запустите процесс:

```bash
debtap имя_файла.deb
```

В процессе утилита запросит ввести имя пакета и лицензию. Можно просто нажимать **Enter**, чтобы оставить значения по умолчанию.

Если не хотите отвечать на вопросы вручную, используйте «тихий» режим:

```bash
debtap -q имя_файла.deb
```

После завершения в текущей папке появится файл с расширением `.pkg.tar.zst`.

> 💡 **Полезные флаги:**
> - `-q` — тихий режим (без интерактивных вопросов);
> - `-Q` — очень тихий режим;
> - `-P` — генерировать `.PKGINFO` и `.MTREE` и выйти (для отладки).

### Шаг 4. Установка готового пакета

Установите полученный архив через штатный менеджер пакетов `pacman`:

```bash
sudo pacman -U имя_файла.pkg.tar.zst
```

### Возможные проблемы и решения

| Проблема | Решение |
|---|---|
| Конфликт зависимостей | Установите недостающие зависимости вручную через `pacman -S` или AUR, затем повторите конвертацию с обновлёнными базами `debtap -u`. |
| Программа не запускается после установки | Проверьте отсутствующие библиотеки командой `ldd $(which имя_бинарника) \| grep "not found"` и установите соответствующие пакеты. |
| Пакет устанавливает файлы в неправильные пути | Используйте ручную распаковку `.deb` (`ar x`, `tar -xf`) либо предпочините Flatpak/AppImage. |

## 2. Сохранение и восстановление настроек рабочего стола

Чтобы не настраивать панели, виджеты, горячие клавиши и темы заново после переустановки системы или экспериментов, используются специальные утилиты или прямой бэкап конфигурационных каталогов.

Ниже описаны варианты для **KDE Plasma** (DE по умолчанию в CachyOS), но большинство подходов применимы и к другим окружениям (GNOME, Xfce, Hyprland и т. д.) с поправкой на конкретные пути.

### Вариант А. Утилита SaveDesktop (графический способ)

`SaveDesktop` умеет сохранять темы, иконки, шрифты, курсоры, плазмоиды, горячие клавиши и конфиги приложений в один архив.

**1. Установка**

```bash
yay -S savedesktop
# или
paru -S savedesktop
```

**2. Сохранение конфигурации (Export)**

1. Запустите **SaveDesktop** из меню приложений.
2. Отметьте компоненты, которые нужно сохранить:
   - Настройки KDE / Plasma (панели, виджеты, темы, обои);
   - Иконки, шрифты и курсоры;
   - Настройки приложений (`~/.config`);
   - Расширения и Flatpak-приложения (опционально).
3. Нажмите **Save / Export** и укажите имя архива, например `my_kachyos_desktop.tar.gz`.
4. Сохраните полученный файл на внешний накопитель или в облако.

**3. Восстановление (Import)**

1. На новой (или свежеустановленной) системе установите SaveDesktop.
2. Нажмите **Import / Restore** и выберите архив `my_kachyos_desktop.tar.gz`.
3. Примените настройки и **перезагрузите ПК** или завершите сеанс (*Log Out* → *Log In*).

### Вариант Б. Konsave (консольный аналог для Plasma)

`Konsave` — лёгкая CLI-утилита, заточенная именно под KDE Plasma.

```bash
# Установка
yay -S konsave

# Сохранить текущий профиль под именем "my-config"
konsave -s my-config

# Экспортировать профиль в архив .knsv (по сути tar.gz)
konsave -e my-config

# На новой системе — импортировать и применить
konsave -i my-config.knsv
konsave -a my-config
```

### Вариант В. Ручной бэкап ключевых конфигураций

Если нужно быстро сохранить конфиги без графических утилит, достаточно заархивировать несколько каталогов в домашней папке.

**Что бэкапить (основные каталоги):**

| Путь | Что хранится |
|---|---|
| `~/.config/` | Настройки большинства программ и рабочей среды (KDE, GTK, браузеры, редакторы и т. д.). |
| `~/.local/share/` | Темы, иконки, плагины, данные приложений, почта, ярлыки. |
| `~/.local/bin/` | Пользовательские скрипты. |
| `~/.bashrc`, `~/.zshrc`, `~/.profile` | Настройки оболочки и переменные окружения. |
| `~/.ssh/`, `~/.gnupg/` | SSH-ключи и GPG-ключи (⚠️ хранить зашифрованно!). |

**Команда для быстрого архивирования (Plasma):**

```bash
tar -czvf my_configs_backup.tar.gz \
  ~/.config \
  ~/.local/share/plasma* \
  ~/.local/share/icons \
  ~/.local/share/fonts \
  ~/.bashrc ~/.zshrc ~/.profile
```

**Команда для восстановления:**

```bash
tar -xzvf my_configs_backup.tar.gz -C ~/
```

> 🔒 **Совет по безопасности.** Кладите архивы с конфигами и ключами в зашифрованный контейнер (например, `gpg -c архив.tar.gz` или используйте `age`/VeraCrypt), особенно если храните их в облаке.

## 3. Чек-лист полной сохранности системы

Перед переустановкой или крупным обновлением рекомендуется сохранить:

1. **Списки установленных пакетов:**

   ```bash
   # Пакеты из официальных репозиториев
   pacman -Qqen > explicit_packages.txt

   # Пакеты из AUR
   pacman -Qqem > aur_packages.txt

   # (Для CachyOS) Пакеты из репозитория cachyos
   pacman -Qqm | grep -E 'cachyos|cachy' > cachyos_packages.txt
   ```

   Быстрое восстановление на новой системе:

   ```bash
   sudo pacman -S --needed - < explicit_packages.txt
   yay -S --needed - < aur_packages.txt
   ```

2. **Архив настроек рабочего стола** (через SaveDesktop, Konsave или ручной tar-архив).
3. **Домашнюю папку (`~/`)** целиком — особенно `Документы`, `Загрузки`, проекты, закладки, пароли (Keepass/Bitwarden-экспорт).
4. **Список включённых сервисов systemd:**

   ```bash
   systemctl list-unit-files --state=enabled > enabled_services.txt
   ```

5. **Бэкап загрузчика и ядра** (опционально, при кастомной конфигурации):
   - `/etc/default/grub`
   - `/etc/mkinitcpio.conf`
   - `/boot/loader/entries/` (при systemd-boot).
6. **Внешний диск или облако** — храните бэкапы хотя бы в двух местах (правило 3-2-1: 3 копии, 2 носителя, 1 вне дома).

## 4. Краткий справочник команд

| Команда | Назначение |
|---|---|
| `sudo pacman -Syu` | Полное обновление системы (**обязательно** перед установкой чего-либо). |
| `yay -Sua` | Обновление только AUR-пакетов. |
| `sudo pacman -U пакет.pkg.tar.zst` | Установка локального пакета. |
| `pacman -Qdt \| sudo pacman -Rns -` | Удаление ненужных (орфанных) зависимостей. |
| `debtap -u` | Обновление баз `debtap`. |
| `debtap -q файл.deb` | Тихая конвертация `.deb` → `.pkg.tar.zst`. |
| `konsave -l` | Просмотр сохранённых профилей Plasma. |
| `tar -czvf out.tar.gz пути...` | Создание tar.gz-архива. |
| `tar -xzvf out.tar.gz -C ~/` | Распаковка архива в домашнюю папку. |

---

*Версия руководства: 1.1. Подходит для CachyOS и других Arch-based дистрибутивов с KDE Plasma. При использовании других DE/HM (GNOME, Xfce, i3, Hyprland и т. д.) пути конфигов могут отличаться — ориентируйтесь на документацию вашего окружения.*
