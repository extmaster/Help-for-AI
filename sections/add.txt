Полный экскурс в мир ИИ: от основ до практики
📦 Уровень 1: Базовые понятия
Что такое модель?
Представь модель как мозг. Но не живой, а математический.

Это огромная нейронная сеть — по сути гигантская таблица из миллиардов чисел (параметров/весов), которые были подобраны в процессе обучения на терабайтах текста. Когда ты пишешь запрос, модель не ищет ответ в базе данных — она генерирует его, предсказывая наиболее вероятное следующее слово, потом ещё одно, и ещё.

Аналогия: Модель — это как очень начитанный человек, который прочитал интернет целиком. Он не помнит конкретные страницы, но у него сформировалось глубокое понимание языка, логики, кода, науки.

Размер модели: что значат цифры?
Когда говорят "70B" или "405B" — это количество параметров (весов) в миллиардах:

Размер	Пример	Нужно RAM/VRAM	Качество
~1-3B	Мелкие модели	2-4 GB	Простые задачи
~7-14B	Qwen 2.5 7B, Llama 3 8B	8-16 GB	Хорошо для кода, чата
~30-70B	Llama 3.1 70B	48-128 GB	Отличное качество
~200B+	GPT-4, Claude Opus	Кластеры GPU	Топовое качество
Чем больше параметров → тем «умнее», но и тем больше ресурсов нужно.

Что такое LLM?
LLM = Large Language Model = Большая Языковая Модель.

Это и есть тот тип моделей, о которых мы говорим: GPT, Claude, Gemini, Llama, Qwen — всё это LLM. Слово "Large" подчёркивает масштаб — миллиарды параметров.

Что такое токены?
Модель не читает буквы и не читает слова целиком. Она разбивает текст на токены — кусочки слов.

text

"Привет, как дела?" → ["При", "вет", ",", " как", " дела", "?"]
Это примерно 6 токенов. В среднем:

1 токен ≈ 4 символа на английском
1 токен ≈ 1-2 символа на русском (русский дороже!)
Почему токены важны для кошелька?
Ты платишь за API за количество токенов:

Input tokens — то, что ты отправляешь (промпт + весь контекст)
Output tokens — то, что модель генерирует в ответ
Пример цен (порядок величин):

Модель	Input (за 1M токенов)	Output (за 1M токенов)
GPT-4o mini	~$0.15	~$0.60
GPT-4o	~$2.50	~$10.00
Claude Sonnet 4	~$3.00	~$15.00
Claude Opus 4	~$15.00	~$75.00
💡 Вот почему у тебя «токены улетели в никуда»! Если ты отправлял длинные промпты или большие файлы с кодом → каждый запрос мог стоить десятки тысяч токенов. А если модель давала развёрнутые ответы, output мог быть ещё дороже.

Что такое контекстное окно?
Это «оперативная память» модели — сколько текста она может держать в голове за один разговор.

text

┌──────────────────────────────────────────┐
│          Контекстное окно (128K)         │
│                                          │
│  [Системный промпт]                     │
│  [Сообщение 1: Пользователь]            │
│  [Ответ 1: Модель]                      │
│  [Сообщение 2: Пользователь]            │
│  [Ответ 2: Модель]                      │
│  [Сообщение 3: Пользователь]            │
│  [...и так далее...]                     │
│  [Последний ответ модели]  ← генерация  │
│                                          │
└──────────────────────────────────────────┘
Модель	Контекст
GPT-4o	128K токенов
Claude Sonnet/Opus 4	200K токенов
Gemini 2.5 Pro	1M токенов!
Важно: Весь предыдущий диалог отправляется заново с каждым запросом! Если у тебя длинная переписка на 50 000 токенов и ты задаёшь ещё один вопрос — ты платишь за 50 000+ input токенов каждый раз. Вот куда утекают деньги.

Что такое температура (Temperature)?
Это «креативность» модели — число от 0 до 1 (иногда до 2):

0.0 — модель выбирает самые вероятные слова. Ответы стабильные, предсказуемые. Хорошо для кода и фактов.
0.7 — баланс между креативностью и точностью. Хорошо для текстов.
1.0+ — модель часто выбирает менее вероятные слова. Креативно, но может нести чушь.

Anthropic — подробнее
Anthropic — это компания, которая делает модели Claude. Основали её бывшие сотрудники OpenAI. Их фишка — безопасность AI.

Линейка Claude (от дешёвого к дорогому):

Haiku — маленькая, быстрая, дешёвая. Для простых задач.
Sonnet — средняя. Лучший баланс цена/качество. Мой «движок», кстати.
Opus — самая мощная и дорогая. Для сложных задач.
Цифры после имени — это версия: Claude Sonnet 4, Opus 4 и т.д.

Что такое «закрытые» vs «открытые» модели?
Закрытые (proprietary): GPT, Claude, Gemini. Работают только через API или веб. Ты не можешь скачать саму модель. Платишь за использование.

Открытые (open-weight): Llama, Qwen, Mistral. Можно скачать и запустить на своём компьютере бесплатно. Но нужно мощное железо.

Что такое API?
API (Application Programming Interface) — это «дверь» для программ.

Когда ты пишешь в ChatGPT через браузер — ты используешь веб-интерфейс. Когда твой редактор кода (Zed, Cursor, VS Code) отправляет запрос к модели — он использует API.

text

Твой редактор                    Сервер OpenAI/Anthropic/Google
     │                                      │
     │──── HTTP запрос ────────────────────→│
     │     "model": "gpt-4o"               │
     │     "messages": [{"role":"user",     │
     │      "content":"Напиши функцию..."}] │
     │                                      │
     │←─── HTTP ответ ─────────────────────│
     │     "content": "def function():..." │
API-ключ — это пароль, который подтверждает, что ты имеешь право отправлять запросы и что деньги за них списываются с твоего аккаунта.

Что такое OpenAI-совместимый API?
OpenAI первыми задали стандарт формата запросов:

JSON

POST /v1/chat/completions
{
  "model": "название-модели",
  "messages": [
    {"role": "system", "content": "Ты помощник."},
    {"role": "user", "content": "Привет!"}
  ]
}
Этот формат стал де-факто стандартом. Почти все инструменты (Cursor, Zed, Continue, Cline) умеют работать с ним. Поэтому, когда другой сервис говорит «мы OpenAI-совместимы» — значит ты можешь подключить его в те же инструменты, просто сменив URL.

CLIProxyAPI именно это и делает: принимает запросы в формате OpenAI, но отправляет их в Gemini/Claude/Codex CLI.

🤖 Уровень 4: Агенты, инструменты, MCP
Что такое AI-агент?
Обычный чат с моделью:

text

Ты: "Какая погода в Москве?"
Модель: "Я не знаю, у меня нет доступа к интернету" ← тупик
Агент — это модель, которая умеет выполнять действия, а не только генерировать текст:

text

Ты: "Какая погода в Москве?"
Агент: 
  1. Думает: "Мне нужно узнать погоду"
  2. ДЕЙСТВИЕ: вызывает инструмент weather_api("Москва")
  3. Получает результат: {temp: -5, condition: "снег"}
  4. Отвечает: "В Москве сейчас -5°C, идёт снег"
Другими словами, агент — это модель + инструменты + цикл принятия решений.

Агент в контексте кода (Cursor, Zed, Claude Code):
text

Ты: "Добавь авторизацию в моё приложение"
Агент:
  1. Читает структуру проекта (инструмент: список файлов)
  2. Читает существующий код (инструмент: чтение файлов)
  3. Думает, что нужно изменить
  4. Пишет новый код (инструмент: запись файлов)
  5. Запускает тесты (инструмент: выполнение команд)
  6. Если тесты упали → читает ошибки → исправляет → снова тесты
  7. Отвечает: "Готово, вот что я сделал..."
Вот почему агентный режим тратит намного больше токенов — модель делает 5-10-20 вызовов инструментов за одну задачу, и каждый вызов — это отдельный запрос к API.

Что такое инструменты (Tools / Function Calling)?
Это конкретные функции, которые модель может вызывать:

text

Доступные инструменты:
├── read_file(path)        — прочитать файл
├── write_file(path, code) — записать файл
├── run_command(cmd)        — выполнить команду в терминале
├── search_web(query)       — поиск в интернете
├── list_files(dir)         — список файлов в папке
└── ...
Модель сама решает, какой инструмент вызвать, на основе твоего запроса. Это и есть «function calling» в настройках.

🔧 Что такое MCP?
MCP = Model Context Protocol. Это открытый протокол, придуманный Anthropic.

Проблема до MCP:
Каждый инструмент и каждый редактор реализовывали подключение к внешним сервисам по-своему. Хочешь подключить базу данных к Claude? Пиши плагин. Хочешь то же для Cursor? Пиши другой плагин. Для Zed? Третий.

Решение — MCP:
text

                    ┌─────────────┐
                    │  MCP-сервер │ (например: PostgreSQL)
                    │  Умеет:     │
                    │  - query()  │
                    │  - schema() │
                    └──────┬──────┘
                           │
                    Стандартный протокол MCP
                           │
          ┌────────────────┼────────────────┐
          │                │                │
    ┌─────┴─────┐   ┌─────┴─────┐   ┌─────┴─────┐
    │  Claude   │   │  Cursor   │   │   Zed     │
    │  Desktop  │   │           │   │           │
    └───────────┘   └───────────┘   └───────────┘
MCP-сервер — это маленькая программа, которая предоставляет набор инструментов через стандартизированный протокол. Любой AI-клиент, поддерживающий MCP, может подключиться к любому MCP-серверу.

Примеры MCP-серверов:
filesystem — чтение/запись файлов
postgres — работа с PostgreSQL
github — создание PR, чтение issues
puppeteer — управление браузером
memory — долговременная память для ИИ
По сути MCP — это USB для ИИ: один стандартный разъём, в который можно воткнуть что угодно.

Что такое Antigravity?
Antigravity — это аналог Claude Code, но от компании Vercel. Это CLI-агент для кодинга, работающий в терминале. Как и Claude Code/Gemini CLI, у него есть бесплатная квота через OAuth-авторизацию. CLIProxyAPI поддерживает его как один из провайдеров — можно залогиниться и использовать через единый API.

Что такое iFlow?
iFlow (и его модель tstars2.0) — это ещё один AI-провайдер/CLI-инструмент, поддерживаемый CLIProxyAPI как один из возможных бэкендов.

💰 Уровень 8: Как не сливать токены
Практические советы:
1. Используй правильную модель для задачи:

text

Простой вопрос          → Haiku / Flash / GPT-4o mini (дёшево)
Написать код            → Sonnet / GPT-4o (средне)
Сложная архитектура     → Opus / o3 (дорого, но стоит того)
2. Не отправляй лишнего в контекст:

Не вставляй весь файл на 5000 строк, если вопрос про одну функцию
Вырезай релевантный кусок кода
3. Начинай новый чат, когда тема сменилась:

Длинный диалог = огромный контекст = дорогие запросы
Каждый новый запрос в длинном чате пересылает ВСЮ историю
4. Используй системный промпт с умом:

Короткий, чёткий системный промпт экономит токены
«Отвечай кратко» — реально экономит output-токены
5. Кэширование промптов (Prompt Caching):

Claude и GPT поддерживают кэширование
Если начало запроса одинаковое — платишь меньше
📊 Шпаргалка-глоссарий
Термин	Что это	Аналогия
Модель (Model)	Нейросеть, генерирующая текст	Мозг
LLM	Большая языковая модель	Тип мозга
Токен	Кусочек слова, единица «валюты»	Слог
Контекст	Всё, что модель «помнит» в рамках диалога	Оперативная память
Температура	Настройка креативности (0-1)	Ползунок «точность ↔ фантазия»
API	Программный интерфейс для запросов	Дверь для роботов
API-ключ	Пароль для доступа к API	Ключ от двери
Агент	Модель + инструменты + цикл решений	Работник с набором инструментов
Инструменты (Tools)	Функции, которые агент может вызывать	Молоток, отвёртка, пила
